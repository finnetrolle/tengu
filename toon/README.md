# :toon - TOON-энкодер

JsonElement → текст TOON ([toonformat.dev](https://toonformat.dev)). Чистая функция на выходной границе: рендерится только то, что уже лежит в JsonElement; truncation/aggregates/empty-states закладывают плагины через `AxiPayloads` (:toolkit) - энкодер о них не знает.

## Состав

| Файл | Что внутри |
|---|---|
| `Toon.kt` | Энкодер. Четыре формы массивов: inline (`key[3]: a,b,c` - только примитивы, коротко), block (примитивы, не влезающие в inline), табличная (`key[N]{f1,f2}:` - объекты с одинаковым набором простых ключей), list-форма (`- элемент` - смешанное/вложенное) |
| `Quoting.kt` | Правила голых строк: без кавычек остаётся «чистая» строка - без разделителя/переводов строк/краевых пробелов, не `#`-комментарий и не выглядит как число/булево/null. Экранирование при кавычке |
| `ToonOptions.kt` | Отступ (2), разделитель (`,`), лимиты inline-формы (8 элементов / 100 символов) |

## Зависимости

- kotlinx-serialization-json - только модель `JsonElement`. Модулей проекта не зависит.

## Тесты

`ToonGoldenTest` - golden-фикстуры в `src/jvmTest/resources/golden/` (`*.json` → `*.toon`); `QuotingTest` - правила кавычек. `./gradlew :toon:jvmTest`

Golden-тесты **фиксируют** формат: любое изменение вывода - осознанное обновление фикстур в том же коммите, иначе совместимость с потребителем (агентом) молча уедет.

Где используется: `:cli` (`render/ToonRenderer.kt`) - единственное место рендера (AXI §1). Архитектура - [ARCHITECTURE.md](../ARCHITECTURE.md).
